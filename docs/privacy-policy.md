# DootDoot Privacy Policy

**Last updated:** 2026-11-08

DootDoot is an unofficial companion app for Tududi. It is not affiliated with tududi or Chris Veleris.

## What we collect

DootDoot does **not** operate a backend that stores your tasks, notes, or projects.

- **Your Tududi data** (tasks, projects, notes, etc.) is sent only to the Tududi server you configure — either [Tududi Cloud](https://app.tududi.com) or a self-hosted instance you control.
- **On-device credentials:** server URL, account metadata, and API tokens / session material are stored in the device’s secure storage and shared preferences.
- **Local notifications:** if you allow notifications, task titles and due times may be stored on the device so DootDoot can schedule reminders. DootDoot does not operate a push notification server; alerts are local to the device.
- **Background refresh:** with an account signed in, the app may periodically contact your configured Tududi server in the background (using the stored API token) to refresh tasks and reminder schedules. Timing is controlled by the operating system. There is no DootDoot analytics or push relay involved.
- **Purchases:** in-app purchase receipts are processed by Apple App Store / Google Play. We store a local flag that Pro is unlocked.
- **Crash / analytics:** none by default. If optional diagnostics are added later, they will be opt-in.

## Account deletion

- **Remove the DootDoot login from this device:** Settings → Sign out / Accounts → Remove. This deletes local tokens and offline cache for that account.
- **Delete your Tududi account or export data:** use your Tududi server (Cloud: Profile settings; self-hosted: ask your admin). DootDoot cannot delete server-side data on your behalf beyond what the Tududi API allows while you are signed in.

## Contact

For privacy questions about DootDoot, open an issue in the DootDoot repository.
